# Security

Dokki Prompter runs entirely in the browser and stores scripts only in the browser's local storage. It has no server and makes no network requests of its own.

If you find a security problem, such as a way to run script content as code, please report it privately through [GitHub's private vulnerability reporting](https://github.com/Noxr3/dokki-prompter/security/advisories/new) rather than in a public issue.
